# Enterprise Asset Management System (MERN Stack)

A secure, full-stack Asset Management System for physical and digital assets, featuring granular role-based access controls, multi-factor logins (Passwords, Google OAuth, Passkeys, TOTP 2FA), custom ID formats, and interactive analytical charts.

## Technology Stack

- **Frontend**: React (Vite), React Router DOM, Tailwind CSS v4, Axios, Framer Motion, Recharts, Lucide Icons, `@simplewebauthn/browser`.
- **Backend**: Node.js, Express.js, Mongoose, Passport.js, `@simplewebauthn/server`, Nodemailer, `speakeasy`, `qrcode`.
- **Database**: MongoDB.

---

## Getting Started

### 1. Prerequisites
- **Node.js** (v18 or higher recommended)
- **MongoDB** running locally on port 27017 or a MongoDB Atlas URI

### 2. Configuration Setup

Create a `.env` file inside the `server/` directory:
```bash
cp server/.env.example server/.env
```
Ensure to review the configurations (especially `MONGODB_URI`, `EXPECTED_ORIGIN`, and credentials).

### 3. Server Installation & Seeding
In your terminal, navigate to the `server/` directory:
```bash
cd server
npm install
npm run seed
```
*Note: The seeding script clears existing databases and seeds 1 Admin, 1 Employee, and 8 asset items with QR codes.*
- **Admin**: `admin@assetmgmt.com` / `Admin@12345`
- **Employee**: `employee@assetmgmt.com` / `Employee@12345`

To start the Express API server (on port 5000):
```bash
npm start
```

### 4. Client Installation & Start
Navigate to the `client/asset-frontend/` directory:
```bash
cd client/asset-frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your web browser.

## Core Features & Testing Walkthrough

1. **Standard & Multi-Option Auth**:
   - Register an account under **Register** to see live password strength and confirm indicators.
   - Set up **TOTP 2FA** inside Settings and scan the QR code to enable authentication lockouts.
   - Save a passwordless **Passkey** biometric credential in Settings to bypass password fields entirely during login.
   
2. **Dashboard & Analytics**:
   - Log in as **Admin** (`admin@assetmgmt.com`) to inspect aggregates (totals, deployed status, branch and department bars).
   - Check upcoming warranties alerts and the latest audit feed changes.
   
3. **Asset Inventory**:
   - Create, edit, search, and filter assets.
   - Custom human-readable Asset IDs are generated dynamically: `{BRANCH}-{DEPT}-{CATEGORY}-{SEQ}` (e.g. `PUN-IT-STA-0001`).
   
4. **QR Code Physical Scanning**:
   - Click the details icon on any asset to display its autogenerated QR Code.
   - Point your mobile device/camera at the QR Code or go to `http://localhost:5173/qr/PUN-IT-STA-0001` to view a public-safe audit record without authentication.

5. **Release & Inbox Requests**:
   - Log in as **Employee** (`employee@assetmgmt.com`) and click **Request Release** on an asset. State the reason and submit.
   - Log in back as **Admin** and approve/reject it from the **Requests** panel, entering admin remarks to automatically update status and send emails.
